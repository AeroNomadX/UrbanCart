# UrbanCart
Fashion & Apparel E-Commerce Website

UrbanCart is a responsive fashion and apparel e-commerce storefront built with HTML5 and CSS3. It was developed as a Web Programming project and focuses on a consistent brand design, a clear shopping flow from deals to categories to products, and a layout that adapts to desktop, tablet and mobile screens.

Features
Two-level navigation: a utility bar plus a main bar with logo, search form (with category selector) and a cart link with item-count badge.
Deal ticker: a full-width yellow banner for running promotions.
Hot Deals section: a featured-deal showcase with badge, was/now pricing, call-to-action button, previous/next controls and slide dots.
Category cards and product grid: four-column card layouts with images, ratings, prices and an Add to Cart button.
Auto-rotating promotional slider: four slides that fade in turn on a 24-second CSS-only animation, with animated text panels.
Product video spotlight: a single-product card with a video and animated taglines.
Trusted partners strip: eight brand logos rendered in white on the navy footer.
Responsive design: breakpoints at 760 px and 420 px for navigation, grids, slider and footer.
Brand design system: all colours are defined once as CSS custom properties.
